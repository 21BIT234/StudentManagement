# Student Management System

A simple Java console-based Student Management System developed using the Java Collection Framework (ArrayList).

## Features
- Add Student
- View All Students
- Delete Student
- Menu-driven console application
- Uses ArrayList as an in-memory database

## Technologies Used
- Java
- ArrayList (Collection Framework)
- Scanner Class
- Object-Oriented Programming (OOP)

## Project Structure
- Student.java
- StudentManagement.java

## How It Works
1. User selects an option from the menu.
2. Student details are entered through the console.
3. Data is stored in an ArrayList.
4. Users can view or delete student records.
5. Application runs until the user chooses Exit.
